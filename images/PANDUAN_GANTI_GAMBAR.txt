=========================================================
PANDUAN MENGGANTI FOTO & GAMBAR DI NABIL BOOK
=========================================================

Folder ini (images/) berisi seluruh aset gambar yang digunakan pada 
halaman web "Nabil Book". Anda dapat dengan mudah mengganti gambar 
apapun tanpa perlu mengubah kode HTML!

Daftar Gambar & Fungsinya:
---------------------------------------------------------
1. profile.jpg
   - Fungsi : Foto Profil Mahasiswa pada Kartu Identitas Web.
   - Cara ganti : Cukup simpan foto baru Anda ke folder ini dengan nama "profile.jpg" (format .jpg).

2. buku-laut-bercerita.jpg
   - Fungsi : Sampul buku novel "Laut Bercerita" (dan preview di Hero banner).

3. buku-bumi-manusia.jpg
   - Fungsi : Sampul buku novel "Bumi Manusia".

4. buku-cantik-itu-luka.jpg
   - Fungsi : Sampul buku novel "Cantik Itu Luka".

5. buku-hujan.jpg
   - Fungsi : Sampul buku novel "Hujan".

6. buku-gadis-kretek.jpg
   - Fungsi : Sampul buku novel "Gadis Kretek".

7. buku-pulang.jpg
   - Fungsi : Sampul buku novel "Pulang".

---------------------------------------------------------
Tips:
- Ukuran rekomendasi untuk sampul buku: rasio 1 : 1.4 (contoh: 400x560 px atau ukuran sampul buku standar).
- Jika nama file baru sama persis (misal 'buku-hujan.jpg'), Anda cukup Timpa / Replace file lama, lalu refresh browser (tekan F5 atau Ctrl+F5).
